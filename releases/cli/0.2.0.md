# cli 0.2.0

## Summary

CLI 専用の Release と、実行中の版を確認する `--version` を追加しました。

## Changes

- Windows、macOS、Linux の amd64 / arm64 向け ZIP を、CLI の Release にまとめて公開します。
- ZIP 名に版を含め、`SHA256SUMS` を添付します。
- `dbeaver-format --version` は CLI の版と、取得できる場合は Git コミットを表示します。
- Go ソースにも版定数を保持し、`go install` から導入した場合も版を確認できます。

## Installation

対象 OS と CPU の ZIP から実行ファイルを PATH に配置してください。
Go を使う場合は次でも導入できます。

```sh
go install github.com/lemonadern/dbeaver-formatter-bridge/cli/cmd/dbeaver-format@v0.2.0
```

## Compatibility

Windows の実 DBeaver では、次の組合せを検証しています。

| プラグイン | CLI | VS Code 拡張 |
| --- | --- | --- |
| 0.2.0 | 0.2.0 | 0.2.0 |
| 0.1.0 | 0.2.0 | 0.2.0 |
| 0.2.0 | 0.1.0 | 0.2.0 |
| 0.2.0 | 0.2.0 | 0.1.0 |

CLI のテストは Windows、macOS、Linux で実行しています。
配布バイナリの利用には Go、Maven、追加 JDK は不要です。
`go install` には Go 1.27.2 以上が必要です。
DBeaver とプラグインは別途導入し、整形時には DBeaver を起動してください。
