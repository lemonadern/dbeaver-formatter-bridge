# plugin 0.2.0

## Summary

DBeaver のプラグイン更新サイトを追加しました。
固定 URL を一度登録すれば、以後は同じ更新サイトから新版を導入できます。

## Changes

- プラグイン専用の `plugin/vX.Y.Z` タグと Release で公開し、CLI と VS Code 拡張の版を独立して管理します。
- 更新サイトの索引は GitHub Pages、各版の p2 メタデータと JAR は GitHub Releases から配信します。
- 従来のオフライン導入用 ZIP とチェックサムも提供します。
- DBeaver のインデント設定を UI スレッドで取得し、起動直後の要求でエディタ設定がバックグラウンド初期化されることを防ぎます。
- 既定のインデントを使う要求でも、UI が応答しない場合は待ち続けず `ui_timeout` を返します。

## Installation

DBeaver の Help → Install New Software → Add で、次の Location を登録し、DBeaver Formatter Bridge を導入して再起動してください。

```text
https://lemonadern.github.io/dbeaver-formatter-bridge/updates/
```

ZIP から導入する場合は `formatter-bridge-update-site-0.2.0.zip` を Add → Archive で指定します。

## Compatibility

DBeaver CE 26.2.2 と、CLI 0.1.0 / 0.2.0 との組合せを検証しています。
Windows の実 DBeaver で 0.2.0 の ZIP 導入、整形、公開済み 0.1.0 の CLI との互換性を確認しています。
p2 の更新経路は macOS と Windows の隔離コピーで、公開版 0.1.0 から未公開の試験版 0.1.1 への移行として検証しています。
公開した 0.2.0 自体の更新サイト経由の導入は、Release と Pages の配信後に別途確認します。
Linux の実 DBeaver GUI と実データベースの SQL 方言は今回の検証範囲に含みません。

正式版 0.1.0 を導入済みの場合は、更新サイトを追加して 0.2.0 へ更新できます。
開発版 `0.1.0.<timestamp>` から正式版 0.1.0 へ戻す場合は、開発版をアンインストールしてから導入してください。
整形には、このプラグインを導入した DBeaver を起動しておく必要があります。
