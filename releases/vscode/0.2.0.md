# vscode 0.2.0

## Summary

VS Code 拡張を専用の Release で配布し、CLI とプラグインの版から独立して管理します。

## Changes

- ローカルインストール用の VSIX と `SHA256SUMS` を、VS Code 拡張の Release に添付します。
- 拡張の変更点と対応版を、この対象のリリースノートで確認できます。

## Installation

VS Code の Extensions → Install from VSIX で `dbeaver-formatter-bridge-0.2.0.vsix` を指定してください。
CLI を PATH に配置し、DBeaver のワークスペースを拡張の設定で指定します。
既定では DBeaver で選択中の SQL タブの接続と、DBeaver のインデント設定を使います。

## Compatibility

VS Code 1.100.0 以上のデスクトップ版向けです。
同じ VSIX の導入を Windows、macOS、Linux で試験しています。
Windows の実 DBeaver では、次の組合せを検証しています。

| プラグイン | CLI | VS Code 拡張 |
| --- | --- | --- |
| 0.2.1 | 0.2.0 | 0.2.0 |
| 0.1.0 | 0.2.0 | 0.2.0 |
| 0.2.1 | 0.1.0 | 0.2.0 |
| 0.2.1 | 0.2.0 | 0.1.0 |

CLI は同梱しないため別途導入が必要で、整形時にはプラグインを入れた DBeaver を起動してください。
Web / Remote 環境と Marketplace での配布は今回の対象外です。
